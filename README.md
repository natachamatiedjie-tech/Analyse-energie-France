# Analyse-energie- HLM France
Ce projet vise à faire une analyse exploratoire de données de consommation énergétiques dans les HLM en France.
## Outils utilisés
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Contenu
1. Nettoyage et préparation des données
2. Analyse descriptive
3. Visualisations graphiques

## Objectif
Montrer ma capacité à manipuler, structurer et valoriser des données avec Python.
